# 本草宇宙 · 首页 3D 百子柜（本次交付）

2026-10-10。首页 `#/home` 星图之后新增「百子柜 · 抽屉墙」版块，144 个抽屉对应 144 张本草知识卡。
线上预览：<https://runner-cpu.github.io/Herbal-Cosmos/>

## 怎么用

- **指针移过抽屉**：抽屉拉开，状态行显示「抽屉：<名称>」。
- **点选抽屉**：右侧浮出知识卡，读出名称、性味、归经、资料分类、分布记录，并给出「打开知识卡 →」链接到真实的 `#/herb?id=…` 页面。
- **键盘**：画布聚焦后方向键在抽屉间移动，回车/空格推拉抽屉。还没选中任何一屉时，第一次按方向键落在第一屉上。
- **查找**：搜索框按名称、拼音、拉丁名、别名命中；分类标签按资料分类筛选并显示命中数量。
- **推回抽屉**：知识卡上的「推回抽屉」按钮，或再按一次回车/空格。

## 交互与降级

| 情形 | 行为 |
|---|---|
| 桌面横屏 | 网格 16×9，整柜铺满画布 |
| 手机竖屏 | 网格自动换成高瘦档（如 8×18），抽屉不会被压成一条 |
| 改窗口大小/转屏 | 重排网格并重新取景，静止画面也补画一帧 |
| 滚动离开视口 | 停止渲染循环，已建好的柜子不卸载 |
| 无 WebGL / `file://` 直接打开 | 画布隐藏，状态行指向「本草图鉴」，筛选与计数仍可用 |
| 系统开启「减少动态效果」 | 只画一帧静态画面，无惯性、无视差 |
| 渲染器下载失败 | 同上降级，并说明「本草图鉴可继续查阅」 |

渲染层（three.js）是**按需包**：柜子滚进视口才开始下载，装好后请 Service Worker 存进独立的 vendor 缓存，之后离线可用。

## 文件

| 文件 | 作用 |
|---|---|
| `assets/js/pages/apothecary-layout.js` | 几何契约：行列选择、抽屉坐标、取景距离、方向键位移。渲染层与键盘导航共用同一份，避免各自漂移。 |
| `assets/js/pages/apothecary-webgl.js` | three.js 渲染层：柜体、抽屉、签牌、灯光、拾取。抽屉与签牌各一个 `InstancedMesh`，整柜两次 draw call。 |
| `assets/vendor/apothecary-webgl.js` | 由 `npm run build:apothecary` 生成（545,191 B / 138,385 gzip，自有预算 560,000 / 145,000），CI 校验可复现。 |
| `assets/js/pages/apothecary.js` | 数据与交互层：筛选、文案、键盘、键盘无障碍、降级、可见性/尺寸观察。 |
| `assets/js/pages/apothecary.browser.js` | 由 `npm run build:browser` 生成的浏览器副本，`index.html` 实际加载它。 |
| `assets/css/apothecary.css` | 深色柜体版块样式，含 1024px / 600px 断点与减少动态效果处理。 |

## 文案边界

版块正文明确写出「抽屉位置由当前知识卡排列决定，**不代表药效高低或重要性**」。
知识卡只复述资料里已有的字段（性味、归经、资料分类、分布记录），不新增任何药效、剂量或推荐用法表述。
