# V5 方剂来源说明（经典原文整理层）

> V5 层于 2026-10-03 引入，把配伍网络的代表方剂从 50 首扩到 100 首。与 V4（`formula-sources-v4.md`）的第三方数字化行级来源不同，V5 采用"经典原文整理"口径，并在每首方剂的 `sourceNote` 中写明整理方式与边界。

## 来源分层

| 层 | 数量 | 来源 | 剂量口径 |
|---|---|---|---|
| 基础精选 | 21 首 | 站内手写精选（`assets/js/data/featured.js`） | 现代克数示例 |
| V4 数字化来源 | 29 首 | huatuo-tcm-dictionary 公开数据（CC BY-NC-SA 4.0），每首带固定行号 URL | 原方文本单位 / 明确标注未载 |
| V5 经典原文整理 | 50 首 | 《伤寒论》《金匮要略》《温病条辨》《太平惠民和剂局方》《脾胃论》《景岳全书》等典籍通行本原文 | 原文单位照录；未整理到剂量的首一律标"所引资料未载剂量" |

## V5 的整理边界

1. **只用通行本原文，不引用第三方数字化副本**：`sourceRefs` 恒为空数组，不伪造行号链接；`sourceNote` 统一注明"据××通行本原文整理，未采用第三方数字化副本"。
2. **组成按原典用名保留**：《伤寒论》的"芍药""栝楼实"、越鞠丸的"抚芎"、黄土汤的"灶心黄土"等古名与特殊物料不擅自映射为现代药材名；解析不到现有知识卡的物料会自动进入"原方物料"层（`formula-material`），明示"原文组成物料；未单独录入药性"。
3. **剂量宁缺毋错**：只有《伤寒论》《金匮要略》《温病条辨》等原文剂量确凿的方剂照录原文（如麻黄杏仁甘草石膏汤"麻黄四两"）；其余一律标注"所引资料未载剂量"。全 50 首不出现现代克数换算。
4. **君臣佐使不推断**：V5 全部 `role` 保持"未标注"，与 V4 一致；配伍洞察中的角色分布只统计明确标注的样本。
5. **证候挂接透明**：`zheng` 字段若命中站内 30 个证候索引（如风寒表证、血瘀证、肝肾阴虚证），构建脚本会把方剂 id 追加进对应证候的 `formulas` 索引（共 11 个证候获得新方）；未命中的证候名（如"湿滞脾胃证""肺热壅盛证"）按实际主治如实书写，不强行挂入索引。

## 复核方式

- `data/sources/formulas-v5.json`：50 首方剂的完整数据与 `sourceNote`。
- `tests/formulas-v5.test.mjs`：唯一性（与基础层/V4 无重名重 id）、来源说明格式、剂量诚实性（≥15 首有原文单位且无现代克数）、证候挂接在生成运行时中真实生效。
- `npm run build:data` 后 `git diff` 应只体现确定性的生成产物变化。
