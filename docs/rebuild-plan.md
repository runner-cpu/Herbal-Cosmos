# 本草宇宙 · 百子万象

## 重新定位

本项目属于科技与创意融合的中华文化数字交互展示。核心问题是：如何把 120 味本草放回生境、放进百子柜，再沿粒子星球追踪它们的名称、形态与公开证据。

## 三个记忆点

1. **六境百子柜**：按山林根境、草甸原野、花野芳香、果实种籽、水泽湿地、菌木阴翳分柜；进入生境后再按形态子类筛选，抽屉展开一味本草。
2. **120 粒子星球**：每味本草是一个粒子，按生境着色；支持旋转、惯性、缩放、搜索、生境筛选和点击侧边档案。

3. **3D 本草识别台与相似药材辨别器**：根据重新检索的植物志和药典形态描述生成可拖动旋转的结构化标本，并对照陈皮／青皮、金银花／山银花、白术／苍术、人参／党参，拆出基原、药用部位、形态和名称边界。模型明确标注为“识别线索”，不是照片和专业鉴定结果。

## 主路径

首页提出问题，追踪台完成“本草 → 典籍 → 方剂 → 当代回响”的证据链，资料库按需打开完整目录，关系海报用于无账号传播。

## 数据边界

`src/data/curated/` 是本轮重新检索的数据输入。每个实体、关系、标本和对照组都含来源编号、定位、访问日期和 `boundary`。资料用于植物学、文献和文化阅读，不提供诊断、剂量、处方、替代治疗或个体化健康建议。

## 验收重点

- 首屏只出现一个主任务；3 分钟内可完成一条关系链。
- 3D 标本支持鼠标拖动和键盘方向键，移动端单栏可用。
- 相似药材对照至少有四组，差异和边界可读，来源可打开。
- 旧 `assets/`、`data/`、`images/`、旧路由、旧 Service Worker 和旧测试已从发布树移除。
- `npm run build`、`npm test` 和语法检查通过后才发布。
