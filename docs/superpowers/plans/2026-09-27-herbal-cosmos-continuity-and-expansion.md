# 本草宇宙数据扩容与首页连续性实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 在保持证据口径透明的前提下，把可浏览精品卡扩展到约 760–800，优先补充可追溯的开放许可图片，并让首页、导航、加载和图表体验形成连续、可验证的产品路径。

**Architecture:** 继续使用零构建 SPA。生成脚本负责把源事实、图片 manifest、覆盖率报告写入运行时数据；页面运行时通过事件接收目录加载进度；首页使用现有 ECharts/组件和统一 CSS token 展示覆盖率洞察。生成文件不直接手改，所有数量由运行时数据或 manifest 注入。

**Tech Stack:** Node.js ESM scripts, vanilla JavaScript modules, ECharts, CSS custom properties, Playwright, Node test runner, GitHub Pages.

## Global Constraints

- 18,817、2,711 等统计数字不能写成当前逐条可浏览数量。
- TCM_KG 只能称为公开资料整理；origin 只能称为资料记录地区；图片只证明来源物种参考。
- 图片优先使用 Wikimedia Commons / iNaturalist 开放许可来源，必须记录作者、许可、来源 URL 和哈希。
- 不打开半成品英文模式，不引入新的构建链，不直接编辑 generated 文件。
- 任何完成声明都必须有本轮命令输出作为证据；发布使用同一 SHA 推送 main 与 gh-pages。
