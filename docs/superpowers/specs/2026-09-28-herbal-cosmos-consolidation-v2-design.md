# 本草宇宙：数据深化与页面收敛设计（第二阶段）

日期：2026-09-28

## 目标

在上一阶段已经上线的 8,818 条名称索引、780 张精品卡、106 种药食同源、50 首方剂和 30 个证候基础上，继续扩大真实可浏览数据，并把站点从“多个内容偏薄的页面”收敛为四个明确入口：首页、探索本草、性味归经、配伍网络。页面视觉统一为连续纸面章节，新增能够解释资料完整度和证候—方剂关系的图表与交互。

## 证据与口径

- `data/sources/open-herb-facts.json` 有 899 条唯一来源事实；其中 803 条归经等核心字段完整，96 条至少有一个字段未录入。
- 现有基础卡 144 条，其中 141 条可与来源事实合并；蜂蜜、粳米、生地黄保留原有药典来源。合并后知识卡目标为 902 条，不包含 5 条仅为方剂组成保留的 `formula-material`。
- 缺失的归经、地区或分类字段显示“未录入”，不能推断、补写或把相近药材资料迁移过来。
- 18,817、2,711 等数字继续只表示资源普查或标准统计，不宣称为当前逐条可浏览记录。
- 图片只接受现有开放许可管道中可精确匹配名称/物种且许可可追溯的结果；没有可靠图片时使用明确占位，不用相似物种冒充。

## 信息架构

### 保留四个主页面

1. 首页：星图、数据档案、学习测验、食养、典籍、文化与项目说明。
2. 探索本草：902 张知识卡与 8,818 条名称索引的浏览和检索。
3. 性味归经：属性矩阵、归经分布、分类流向和资料完整度洞察。
4. 配伍网络：方剂网络与证候药链两个页内视图。

### 合并与兼容

- 删除独立学习舱页面；测验完整嵌入首页学习路径，首页直接显示题目、进度和本机足迹。旧 `#/learn?step=N` 重定向到 `#/home?anchor=home-learning&step=N`。
- 删除独立病证药链页面；在配伍网络页增加“方剂网络 / 证候药链”切换。旧 `#/zheng?z=...&f=...` 重定向到 `#/formula?view=zheng&z=...&f=...`。
- 主导航只显示四个入口；“更多”不再承担页面导航，收藏、主题和来源使用现有全局控件与首页锚点。

## 数据层设计

`build-expanded-data.mjs` 不再用固定 780 截断，也不再只接纳 `hasCompleteFacts` 的记录。所有 899 条来源事实参与合并：基础卡按名称或唯一别名补充来源字段，余下事实生成新卡。每张非方剂材料卡新增 `factStatus: complete | partial | legacy`，由纯函数根据缺失字段计算；构建报告新增 `partialFacts`、`legacyFacts`、`meridianCovered`、`taxonomyCovered` 和 `factCoverageRatio`。

验证器允许 partial 卡存在，但要求名称、来源、说明和可追溯 `sourceRefs`；缺失字段必须是空数组或明确“未录入/未分类”，不得写成推断值。完整卡与部分卡的合计必须等于知识卡总数，运行时、报告和版本对象必须一致。

## 可视化与交互

### 资料完整度矩阵

在探索本草页新增“资料完整度 × 传统分类”矩阵：横轴为图片、归经、地区、分类学、逐行来源五类资料，纵轴为主要功效分类，色深表示覆盖率。点击单元格直接筛选该分类和资料状态，并在证据区列出缺口与代表记录。

### 配伍双视图

配伍页页内切换保留同一个上下文：从证候药链点方剂切回网络时聚焦对应节点；从方剂检查器点证候切到药链时保留方剂高亮。URL query 保存 `view`、`z`、`f`，刷新后状态不丢失。

### 首页学习工作台

首页学习区由路径说明升级为可答题工作台。题目、反馈、下一题和本机统计仍复用现有逻辑；五步路径改为首页/核心页锚点，不再跳往已删除路由。反馈使用 `aria-live`，答题后更新首页进度与探索足迹。

## 视觉系统

- 所有页面使用同一 `--paper` 基底和 `--paper-2` 轻层级；不在浅色页面中插入突兀深色分析区。
- 页面章节由细线、编号、章节点和微弱纸纹连接，而不是不同背景色硬切。
- 图表容器从“阴影卡片”改为连续分析章：低阴影、同色边界、统一标题高度和说明位置。
- 主要标题、数字和小标签使用一致字阶；数字启用 tabular figures。
- 动效限于 opacity/transform；`prefers-reduced-motion` 下禁用视差、自动聚焦动画和悬浮位移。
- 375px 下双视图、矩阵证据区和学习工作台改为单列，触控目标至少 44px。

## 多角度质量改进

- 数据可信度：分层显示完整/部分/原方材料，所有数字由数据源驱动。
- 信息架构：减少路由和导航选择，保留旧链接兼容。
- 视觉连续性：统一表面 token、章节节奏、标题和图表容器。
- 可视化解释力：新增可追溯的资料缺口矩阵，并把证候图纳入核心关系页。
- 交互闭环：图表点击可筛选或聚焦，不新增死按钮。
- 无障碍：保留跳转链接、焦点样式、键盘切换、图表文字证据和实时播报。
- 性能：不新增依赖；902 卡继续分页，图表只在对应视图可见时初始化。
- 移动端：桌面和 375px 均检查横向溢出、抽屉、触控和图表证据区。
- 搜索与 SEO：旧路由不返回空页面；页面标题随合并后的视图变化。
- 发布安全：生成文件只由脚本产出；完整测试后同一 SHA 推送 main 与 gh-pages。

## 验收

- 知识卡为 902 条（899 条开放来源事实 + 3 条现有药典基础卡），另有 5 条原方材料，报告与运行时一致。
- 首页、探索本草、性味归经、配伍网络四个主入口可完整到达所有内容。
- `#/learn` 和 `#/zheng` 自动兼容跳转，不出现 404 或空页面。
- 首页可直接答题；配伍页可在方剂网络和证候药链间双向聚焦。
- 资料完整度矩阵可点击筛选，并有文本证据区。
- 日间、夜读、古籍三主题下页面背景连续；桌面与 375px 无横向溢出。
- 单元测试、数据验证、应用验证、Node 语法检查和 Playwright 桌面/移动测试全部通过后发布。
