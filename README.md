# 本草宇宙 · HERBAL COSMOS

> 以 18,817 种中药资源为星辰的文化知识图谱 —— 一个数据可视化、强交互的中医药科普网页应用。

「本草宇宙」是一枚**单文件、零构建**的原生 Web 交互式数据可视化作品，把中药资源普查、药典典籍、方剂配伍、性味归经、药食同源等结构化知识，编织成"星云 → 配伍 → 生活 → 历史"的沉浸式叙事。它源于**全国大学生数字媒体科技作品及创意竞赛**赛道，以"新中式数据美学"呈现中医药文化的三重叙事：**天人合一、生生之道、薪火相传**。

## 在线体验

- **直接打开**：将仓库中的 `index.html` 下载到本地，用任意现代浏览器（Chrome / Edge / Firefox / Safari）双击打开即可，无需服务器、无需安装依赖。
- **推荐环境**：桌面端 Chrome 或 Edge 体验最佳（3D 星云粒子与 ECharts 交互完整）；移动端已做响应式适配。

> 注：图表渲染依赖 ECharts CDN（jsDelivr），首次加载需联网；若网络受限，页面会自动降级为文字说明，不影响浏览。

## 核心特性

### 开源参考与借鉴边界
- 参考 GitHub `cheny6/KGAT-RAG-Traditional-Chinese-Medicine-Knowledge-Graph-Retrieval-Augmented-Generation-System` 的领域实体关系组织方式，强化“证—方—药”链路的可读性；本项目不复制其模型或数据。
- 参考 GitHub `jjasminum02-debug/tcm-formula-knowledge-graph` 的 provenance（来源追溯）思路，为知识卡和网络增加来源徽标、来源与方法说明。
- 参考 GitHub `viviiviiikikiikiii/OptiSyn` 的可解释关系网络方向，为配伍网络增加方剂聚焦、关系统计与邻域提示。
- 以上项目仅作为交互与信息架构参考；本项目仍保持零构建、浏览器离线可运行、公开数据来源可追溯的约束。

### 1. 3D 星云首页（Canvas 粒子引擎）
- 自研 Canvas 3D 投影引擎，**63 味代表药材**化作可点击的星点悬浮于星空，药食同源与高频药材以印章级亮星呈现。
- **交互**：拖拽旋转、滚轮缩放（缩放到达边界自动放行页面滚动）、点击星点直达药材详情、悬停显示药名。
- **分级标签**：默认只标注"药食同源 + 亮星"避免拥挤，滚轮放大后展示全部药名。

### 2. 九大页面 / 模块
| 模块 | 内容 | 可视化形态 |
|---|---|---|
| 首页 | 品牌叙事 + 五大数据卡 + 三条文化叙事 + 精选本草 | 3D 星云粒子引擎 |
| 药材星图 | 63 味代表药材总表，支持四气/五味/功效筛选与关键词过滤 | 筛选芯片 + 数据表格 |
| 药材详情 | 药典属性（四气/五味/归经/功效）、归经画像、性味定位、相关方剂 | 环形图 + 坐标散点 + 卡片 |
| 性味归经 | 四气×五味热力矩阵 + 十二经归经分布 | ECharts 热力图 + 柱状图 |
| 配伍网络 | 12 首代表方剂 × 药材二部图，支持跨页联动定位 | 力导向图 + 方剂卡片 |
| 病证药链 | 证 → 方 → 药三阶链路 | 桑基图 + 证候卡片 |
| 典籍时光 | 历代本草典籍收药规模演进 | 柱状图 + 时间线 |
| 药食同源 | 国家目录 106 种中的代表物质，按用途筛选 | 卡片矩阵 |
| 文化与非遗 | 中医药相关国家级非遗代表项目 | 图文卡片 |

### 3. 跨页面联动（状态中枢）
- 全局 `store` 单一事实源 + 发布订阅：在详情页/配伍网络/星云之间通过 hash 路由与 query 参数双向联动。
- 例：药材详情页点击"相关方剂" → 配伍网络页自动**高亮该方剂节点 + 卡片"定位"标识**。

### 4. 数据可信度体系
- 每个知识卡标注 **"数据来源：中国药典 2020 / 本草纲目 / 普查数据"** 徽标，透明化数据层级，学术严谨。
- 全站附"仅供文化科普，不构成医疗建议"合规声明。

## 技术架构

**技术栈**：原生 HTML5 + CSS3 + JavaScript（ES6+），零框架、零构建工具、单文件交付。

| 层 | 技术 | 说明 |
|---|---|---|
| 渲染 | Canvas 2D（自研 3D 投影）+ ECharts 5.6.0 | 星云粒子引擎手写；统计图使用 ECharts |
| 路由 | Hash 路由（`#/route?param=value`） | 无需服务器，支持刷新、前进后退 |
| 状态 | 单一 `store` + 发布订阅（`notify`/`setSelected`） | 全局联动的事实源 |
| 图表管理 | `chartManager`（Map 实例池） | 路由切换时主动 `dispose` 旧实例与 `ResizeObserver`，防内存泄漏 |
| 外部资源 | 仅白名单：ECharts（jsDelivr + SRI 校验）、字体（妙搭自托管镜像） | 安全、可溯源 |

### 关键设计：三级数据分层
解决"18,817 种全量数据 vs 浏览器性能"的矛盾：

| 数据层级 | 数量 | 交互能力 | 渲染方式 |
|---|---|---|---|
| 药典精品层 | 63 味代表药材 | 完整点击/详情/联动 | 高精度 3D 星点 + 详情页 |
| 普查全量层 | 18,817 种（数据叙事层） | 统计口径展示 | 数据卡片/图例说明 |
| 动态筛选子集 | ≤500（筛选结果） | 完整交互 | 表格/图表重新渲染 |

## 数据层设计

### 数据结构
- **HERBS（药材）**：63 味代表药材，字段含 `id / name / pinyin / qi（四气）/ wei（五味）/ meridian（归经）/ eff（功效）/ cat（分类）/ source（来源）/ food（药食同源）`。
- **FORMULAS（方剂）**：12 首经典代表方，字段含 `id / name / source（出处）/ eff / note / monarch-minister（君臣佐使）/ herbs（组成）/ zheng（主治证型）`，组成均为**真实完整方**（如六味地黄丸六味俱全、麻黄汤含苦杏仁）。
- **ZHENGS（证候）**：18 个常见中医证候，映射"证 → 方 → 药"链路。
- **CLASSICS（典籍）**：从《神农本草经》到《中国药典》的历代典籍规模数据。
- **FOODS（药食同源）**：国家卫健委目录中的代表物质。

### 数据来源（可溯源）
- **第四次全国中药资源普查**：中药资源总量 18,817 种（植物 15,321 / 动物 2,517 / 矿物 153 / 菌物 826；特有 3,151、濒危 464；普查记录约 2,000 万条）。
- **《本草纲目》**：1,892 药 / 11,096 方 / 1,160 图，52 卷约 190 万字，16 部 60 类。
- **《中国药典》2020**：一部 2,711 种，"药材和饮片"616 种。
- **国家卫健委药食同源目录**：106 种（2024，动态更新）。
- **国家级非遗名录**：中医药相关代表性项目。

## 视觉设计系统

### 新中式数据美学
- **配色令牌**：黛青（深空蓝，`#1B2A41` 系）、宣纸底（米白 `#F6F1E5` 系）、鎏金点缀（`#C9A24B` 系）、赭石/朱砂强调（`#A64A38` 系）。
- **本草印章**：每张药材知识卡右上角有一枚动态生成的"本草印章"（含药材名缩写 + 性味），仿古籍钤印，是作品的**视觉记忆点**。
- **归经星轨**：首页星点带缓速公转，不同轨道色系对应不同归经。
- **字体**：思源宋体/楷体类衬线标题 + 阅读感正文，落款式英文小字（HERBAL COSMOS）。

### 响应式
- 桌面端（≥769px）：多栏布局、悬停增强。
- 移动端（≤768px）：汉堡导航、筛选换行、表格横向滚动、触控目标 ≥44px。

## 性能与健壮性

1. **内存管理**：`chartManager` 统一注册/销毁 ECharts 实例与 ResizeObserver，杜绝路由切换累积泄漏（演示中高频切页不卡顿）。
2. **CDN 失败降级**：ECharts 加载失败时，三层防护（全局守卫文案 + 视图级守卫 + 路由 try/catch）保证页面主体正常，绝不白屏。
3. **事件治理**：星云滚轮缩放只在有效区间接管，到达边界放行页面滚动；搜索输入不强制跳转、回车才导航。
4. **渲染性能**：星点按视口裁剪 + 分级标签；图表按需初始化，切页才渲染。
5. **代码质量**：内联 JS 全量通过 `node --check` 语法校验；无本地资源路径、无外部非白名单依赖。

## 数据来源与合规声明

- 数据基于公开权威来源整理：第四次全国中药资源普查、明·李时珍《本草纲目》、国家药典委员会《中国药典》2020、国家卫健委药食同源目录、国家级非遗名录。
- 方剂组成按经典原著还原，标注出处；知识卡均标注"数据来源"徽标，未覆盖字段标记"待考"，不做编造。
- **内容声明**：本站内容仅供文化科普与学习，不构成医疗建议；用药请遵医嘱，特殊人群慎用药食同源物质（以官方公告为准）。

## 竞赛与后续规划

本项目为**全国大学生数字媒体科技作品及创意竞赛**参赛作品，叙事主线：

1. **天人合一**：道地药材 × 应季本草（节气与地域的对应秩序）。
2. **生生之道**：单味药 → 方剂配伍，体现"君臣佐使"的组织智慧。
3. **薪火相传**：从《神农本草经》到《中国药典》的两千年典籍传承。

**已交付（P0 必保）**：药材星云、配伍网络、药食同源、典籍时光 + 性味归经、病证药链、详情联动、收藏。
**规划中（P1/P2 加分）**：炮制时间线、非遗专题深化、AIGC 问答助手、全量 18,817 种数据的懒加载分层（Web Worker 粒子 + 空间索引）。
