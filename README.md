# 本草宇宙 · 一味之证

这是一个面向普通公众的本草文化交互展。项目把“一味本草如何被看见、命名、记录并留下证据”做成一条可以亲手追踪的证据链。

在线地址：<https://runner-cpu.github.io/Herbal-Cosmos/>

## 体验重点

- **百子柜主入口**：16 味重新检索的精选本草以木柜抽屉呈现，按药用部位筛选，抽出后即时展开身份卡和证据边界。
- **关系星图**：从当前本草沿着方剂、典籍 / 研究史和公开来源追踪；来源支持边以浅色单独呈现，避免把引用误读为药材关系。
- **结构化识形台**：在一味档案中拖动观察根、叶、果皮和花蕾等识别线索；没有标本的条目明确显示“待补”，不复用其他物种模型。
- **相似药材辨别器**：对照陈皮／青皮、金银花／山银花、白术／苍术、人参／党参，直接查看基原、部位、形态和名称边界。
- **证据链工作台**：本草 → 典籍 → 方剂 → 当代回响。每个节点都能打开来源抽屉。
- **关系海报**：无需登录，生成可保存的 SVG 阅读海报。

## 数据来源与边界

`src/data/curated/` 是本轮重新检索的数据集，不复用旧项目的数据结构。当前包括 16 味本草、3 首方剂、3 个文化锚点、20 条关系、6 个结构化标本和 4 组相似药材对照。每个实体和关系都记录来源、定位、访问日期与边界说明。

内容用于植物学、文献和文化阅读，不提供诊断、剂量、处方、替代治疗或个体化健康建议。相似药材页面用于理解差异维度，不能替代专业鉴定。

## 本地运行

```sh
npm ci --ignore-scripts
npm run build
npm test
npm run serve 4173
```

打开 <http://localhost:4173/>。项目使用原生 ES Modules、SVG、CSS 3D 和静态 JSON，可直接部署到 GitHub Pages。

## 评分对应

作品围绕“科技+创意讲好中国本草故事”设计：证据链是原创主交互，3D 识别台和相似药材辨别器承担展示记忆点，来源抽屉与数据校验保证可验证性，三分钟演示可从一个入口完成闭环。
