# 本草宇宙 · 百子万象

这是一个面向普通公众的本草文化交互展。项目把本草放回生境，把 120 味条目组成一颗可以旋转的粒子星球，再把每一味的身份、证据和阅读边界拆成可追踪的档案。

在线地址：<https://runner-cpu.github.io/Herbal-Cosmos/>

## 体验重点

- **双入口宇宙首页**：首页只保留世界观、规模和两扇入口，百子柜与粒子星球各自拥有独立舞台。
- **六类生境百子柜**：山林根境、草甸原野、花野芳香、果实种籽、水泽湿地、菌木阴翳组成三列两排的真实柜墙；先点生境大区，再从 20 个带编号、名称和形态标签的小抽屉中抽出一味本草。抽屉以 Z 轴透视滑出，右侧米纸详情同步展开，深度条目可直接进入相似药材辨别。
- **四页探索地图**：首页用四张窄卡说明百子柜、粒子星球、一味档案、资料库各自解决的问题，用户可以先理解路径，再进入对应舞台。
- **粒子星球**：120 味本草各是一颗粒子，按主生境着色；支持拖拽旋转、滚轮 / 触控缩放、搜索、筛选、点击详情和键盘目录回退。
- **关系星图**：从一味档案沿着方剂、典籍 / 研究史和公开来源追踪；来源支持边以浅色单独呈现，避免把引用误读为药材关系。
- **结构化识形台**：在一味档案中拖动观察根、叶、果皮和花蕾等识别线索；没有标本的条目明确显示“待补”，不复用其他物种模型。
- **相似药材辨别器**：对照陈皮／青皮、金银花／山银花、白术／苍术、人参／党参，直接查看基原、部位、形态和名称边界。
- **照片对照与来源卡**：四组相似药材都配有真实植物照片；点击任意照片可放大，并查看作者、数据集、许可、原始媒体和观测记录。对照照片保存在 `src/assets/comparisons/`，元数据随 `comparisons.json` 维护。
- **看图识本草**：资料库内置随机四选一识别模式；名称先隐藏，答题后揭晓学名、药用部位和主生境，识别过程始终可以回到照片来源卡核对。
- **证据链工作台**：本草 → 典籍 → 方剂 → 当代回响。每个节点都能打开来源抽屉。
- **关系海报**：无需登录，生成可保存的 SVG 阅读海报。
- **本草级图片档案**：120 味本草各有一张本地植物观测缩略图，百子柜抽屉、粒子星球详情、一味档案和资料库都会显示对应图片；图片元数据在 `src/data/curated/herb-images.json` 中记录 GBIF / iNaturalist 来源、作者和许可，页面不依赖外部图片站点运行。

## 数据来源与边界

`src/data/curated/` 是本轮重新检索的数据集。当前包括 120 味本草（16 味深度条目 + 104 味拓展条目）、3 首方剂、3 个文化锚点、20 条关系、6 个结构化标本和 4 组相似药材对照。每味本草采用“一个主生境 + 多标签”规则，记录 `habitat`、`morphology`、`partUsed`、`depthLevel`、来源和阅读边界，后续可直接追加到现有六类生境。

本草图片来自 GBIF 公开观测媒体，优先使用 iNaturalist 研究级观测的中尺寸图像并压缩为网页缩略图；每条图片保留原始媒体地址、观测页、作者与许可信息。图片用于形态初识，不把照片当作专业鉴定结论。

四组相似药材的外部对照照片也来自 iNaturalist / GBIF 公开媒体，抓取脚本为 `scripts/fetch-comparison-images.mjs`。图片展示始终保留来源入口和许可字段；若来源记录没有标注许可，页面会明确显示“页面未标注许可”。

内容用于植物学、文献和文化阅读，不提供诊断、剂量、处方、替代治疗或个体化健康建议。相似药材页面用于理解差异维度，不能替代专业鉴定。

## 本地运行

```sh
npm ci --ignore-scripts
npm run build
npm test
npm run serve 4173
```

打开 <http://localhost:4173/>。项目使用原生 ES Modules、SVG、CSS 3D 和静态 JSON，可直接部署到 GitHub Pages。

## 评分对应

作品围绕“科技+创意讲好中国本草故事”设计：证据链是原创主交互，3D 识别台和相似药材辨别器承担展示记忆点，来源抽屉与数据校验保证可验证性，三分钟演示可从一个入口完成闭环。
