# 本草宇宙 · 文化赛道改版报告

日期：2026-10-08。状态：文化架构、页面实施、本地总检与GitHub Pages代码发布均已完成。

## 本轮目的

按用户提供的“一扇门、四幕戏、一段尾声”框架，将功能页面组织成文化旅程。主要任务是厘清每页职责、收拢重复内容，使“民族文化、创新表达”能通过正文与实际交互被理解。完整设计见 [文化赛道框架](../docs/competition-framework.md)。

## 原结构的问题与调整设计

| 问题 | 调整方向 | 验证方式 |
|---|---|---|
| 默认首页聚合资源、图表、食养和典籍，首屏无法明确参赛主题 | 默认序章说明文化主线；“源”首页聚焦星图、精选与馆藏 | 新访问到序章，可直接进入展览或图鉴 |
| 更多菜单、证候独立路由与配伍工作区存在重复归属 | 六项文化主导航，图鉴作工具；证候药链收进“术”页内标签 | 新导航无重复，旧 `#/zheng` 链接仍可达 |
| 数据页面主要展示图，文化内容只作装饰文案 | “道”解释传统分类，“术”解释角色并保留证据检查器 | 文化解释可见，图表点击后出现具体样本 |
| 非遗、食养、典籍散落首页与学习舱，内容长度失衡 | “传”作为独立文化页，按三个展区分层 | 六专题、106项目录与典籍入口可达，无重复长列表 |
| 学习以识药题为主，缺少参观后的文化反馈 | “传习”加入基于已展示内容的文化题与解释 | 回答正确或错误均得到解释，不虚构学习成就 |
| 收藏与足迹缺少文化旅程语义 | 旅程面板汇总足迹与练习，保留独立收藏抽屉 | 收藏、访问记录可回到知识卡，本机边界清晰 |
| 夜读与浅色主题已形成，水墨表达仍不独立 | 添加水墨古籍主题，图表与全局工具采用同一主题令牌 | 三主题下标题、卡片、图例、tooltip、抽屉可读 |

以上调整已落地。方剂网络、样本统计、目录、证候分别占一个视图；首页覆盖图与图表组件按需加载。文化题反馈提供回读展柜与已有外部来源的链接。序章采用SVG星轨，首页保留Canvas星图，新增水墨古籍主题和矢量本草印章。

最终检查另修复了三个实际问题：移动端序章说明文字溢出、标题动效丢失换行，以及答题后切主题或回读来源导致题目锁死。带题号的下一题会更新路由，切换方剂视图保留药材上下文，网络连线提示展示方剂和药材名。

矩阵增加“四气待补”灰行，保留缺四气卡的已知苦、辛记录，让五个主味列合计与柱图一致。四气占比注明有效900味与待补2味；类别筛选使用子样本，独立归经桑基注明仍为全馆藏。淡、涩保留为补充图例，不强配五行。

## 框架资料中的事实风险

| 原方案表述 | 应采用的口径 | 原因 |
|---|---|---|
| 18,817种民族医药资源，18,817颗星 | 全国中药资源普查背景；星图是意象，可点击样本以实际卡为准 | 没有特定民族资源细分表或18,817条完整卡可据 |
| 365→5,911代表本草药物增长 | 不同文献节点分别注明药物数与标准项数 | 药典四部合计标准与古籍药物不可同轴比较 |
| 365对应周天 | 作为传统象征讲述 | 不等于现代历法或天文学精确结论 |
| 四气等于四时之气、五味等于五行之味 | 解释中医传统联系，同时保持实际属性与统计规则 | 文化联系不等于季节决定药性，亦不代表所有民族医学 |
| 国家级非遗六项为针灸、炮制、养生、诊法、灸法、育婴 | 使用实际六专题：针灸、炮制、藏医药浴、诊法、养生、同仁堂 | 原方案清单与项目现有资料不符，不能补造名录项 |
| 非遗场景照片 | 标注现有六图为AI概念插画 | 原图片账本全部为 `PROJECT-EDUCATIONAL` |
| 君臣佐使解释涵盖100首方 | 文化通用解释；实际角色统计只取明确标注的子样本 | V4、V5未逐味标注角色，不能推断补全 |
| 将2,275个候选直接放量 | 不按设计文档自动批准待审索引 | 候选仍需行级来源与噪声复核，当前review为1,487条 |

《本草纲目》旧数据的“1590年刊行”应修为通行书目中的1596年刊行，并区别成稿与刻板时间。2020版药典作为历史资料呈现，不能写作2026年的现行标准。

## 本轮证据读取

UNESCO针灸与藏医药浴条目读取返回HTTP200且标题对应。中国非物质文化遗产网通过官方项目数据接口取得炮制Ⅸ-3、诊法Ⅸ-2、养生Ⅸ-10具体扩展项、同仁堂Ⅸ-7的条目，并逐一直接读取四个公开详情页，全部返回HTTP200且标题、编号与公布批次对应。养生是站内专题名，来源链接精确到“中医养生（中医传统导引法）”，不泛称所有生活方式均为非遗。

国家药监局药典2020公告本轮非交互读取返回HTTP412，未取得官方正文字节。既有来源清单中的镜像与学术统计只按其真实证据层级保留；不能以可打开镜像代替“本轮已核验官方内容”。全国18,817资源叙事沿用原数据快照，尚需进一步补充直接可核对的普查原表。1596年刊行在本轮可访问二级书目资料中得到交叉核对，具体官方馆藏版次仍待完善。

无新增栅格图像生成。原非遗概念插画继续保留其明确标识，与开放许可药材来源照片分别说明。

## 仍然存在的边界

现有样本以中医本草与方剂为主，民族医药专题仍需按各自理论和文献扩充，不能用中医分类替代它们。古籍专题尚未做到每条引文的影印本页码。食药目录和药典是明确年份快照，不保证同步现行全部目录。278张缺图、部分事实字段、响应式缩略图与真实移动设备测试仍需后续建设。

这些边界随实际资料写明；文化改版的目标是让当前证据更清晰，而不是改变已有资料的可信等级。
