# 本草宇宙 · 参赛细节打磨与发布验收

日期：2026-10-08。基线：`6e47096`，文化四幕架构与数据 v10 已落地。本轮针对实测报告复现问题、修复交互和移动布局；没有扩张药材数据或生成新的药材图像。当前框架见[文化赛道文档](../docs/competition-framework.md)，可复制介绍与演示路径见[参赛说明](../docs/competition-presentation.md)。

## 关键问题与修改

| 问题 | 根因与处理 | 验证方式 |
|---|---|---|
| 离开知识卡后顶部残留药材条 | 原组件监听选择而不限定路由。现在仅在对应知识卡显示，关闭、离页或失效 ID 时清空 DOM；显式星图/图表定位保留药材选择 | 七个主入口、联动链接、关闭、失效 ID、导航占位与主题回归 |
| 关闭药材条后切主题又出现 | 主题刷新重新发出药材选择事件。保留当前详情路由的关闭状态，真实换页后解除 | 关闭→三主题→离页→重访详情 |
| 小屏收藏按钮被遮挡 | 顶部对齐滚动未为 sticky 外壳留白，另有异步搜索重开遮挡。增加导航滚动留白与44px按钮尺寸，并修搜索关闭状态 | 1440/375/320px，start/center/自动滚回，实际中心命中与鼠标点击 |
| 抽屉取消收藏后详情按钮仍显示已收藏 | 详情按钮未监听抽屉的收藏事件。统一事件同步与存储会话回退 | 角标、详情、抽屉0→1→0；禁用 Storage 后重复操作 |
| 搜索“枸杞”出现药性待补的重复卡 | 原方物料与知识卡一起被搜索，索引又被辅助实体遮去。卡建议与 Enter 只取902卡，分组显示知识卡/方剂/名称索引，索引明确“仅名称 · 无药性” | 枸杞、地骨皮别名、公丁香、纯索引名称、键盘跨组跳转 |
| 手机下拉遮住搜索输入框 | 下拉固定在54px，而手机导航实际为两行105px。改用实际 header 高度，并限制列表不超视口 | 320×700、375×812、375×400，输入中心可达且能继续编辑 |
| 目录加载完成/失败后搜索重新弹出 | 异步回调无条件重建建议。仅更新仍打开且有焦点的搜索；后台资料刷新保留滚动和已有搜索状态 | 延迟分块→进入详情/按 Esc→完成或失败；320px收藏真实中心不被遮挡 |
| 序章首访偷偷下载图表库 | ECharts运行时已有按需加载，但安装缓存仍预取完整库。移出安装清单，改为版本化按访问缓存，命中不后台重拉 | 初次序章零ECharts/索引分块请求，访问后离线图表，首次直接进入图表的缓存衔接 |
| 离线缺少字段工具 | `field-utils.js` 已在HTML使用，却不在外壳缓存 | 加入外壳缓存，离线图表读取902卡且无脚本失败 |
| 阅读Markdown污染离线首页 | 原SW将任意成功导航写成 `index.html`，文档可覆盖应用外壳 | 限定应用入口更新外壳；阅读文档后离线返回展馆 |
| 典籍时间线不能展开出处 | 静态节点没有来源层次入口 | 七节点采用原生 details，区分导读/二级书目/官方公告；Enter与Space可操作，主题刷新保留展开状态 |
| 手机配伍按钮逐字换行、夜读重置按钮偏暗 | 控件收缩与固定暗色文字 | 小屏控件保持完整短语；重置按钮采用主题前景色，验证对比度与点击 |

占位图已用药名和“照片待补”标识，网络失败另标“加载失败”；本轮保留并回归该状态。没有用生成的识别照片填补缺图。首页资料分类增加可见口径说明与数字提示，不将分类数量表述为药效排名。

## 数据快照与边界

生成报告仍为902张知识卡、961条运行时实体、100首方剂、58个证候、106项食药条目；8,818条名称可检索、1,487条待审、45个按需分块。辅助实体17条目录身份与42条原方物料不混入知识卡搜索或属性图样本。

图像账本核验为624张有图卡、562个唯一文件、278张待补；唯一图像文件合计66,743,979字节。用户检查报告中的“511+144”不作为当前标准，数字以生成账本与逐图许可清单为准。来源生物照片不自动证明药用部位或炮制状态。TCM_KG内容许可未明确，本轮说明不将其误写为CC-BY。

这次测量的后台累计字节减少约26.5%。后续增加移动布局、缓存和搜索小修使外壳字节略有变化；最终应用预算由验证器列在下方。完整知识卡的13个数据脚本原始915,096字节、逐文件gzip估算166,200字节，数据未改变。ECharts原始1,034,102字节、gzip估算336,173字节。gzip由zlib计算，不代表Pages实际Content-Encoding或传输。

知识卡9个扩充块仍为首屏有序 `defer` 依赖，尚未改为按路由取数；名称索引45块已经按进入索引/开始搜索加载，不能将既有行为描述为本轮新增。初装外壳仍可能重复请求已加载脚本；直接首访图表且早于SW接管时，已使用的图表库可能需要一次补缓存请求。未宣称更换ECharts按需构建或首屏耗时同比改善。
